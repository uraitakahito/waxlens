# 事例集(waxlens-corpus)

WACZ 標本集 [`uraitakahito/waxlens-corpus`](https://github.com/uraitakahito/waxlens-corpus)
を使うと、**各 rule の失敗例**と **profile 差**を系統的に確認できる。

各標本の期待結果は `manifest.json`(waxlens が実際に `runValidation` した出力)に集約されている。
rule 一覧と severity matrix は [`docs/rules.md`](rules.md)、JSON 出力の形は [`docs/json-schema.md`](json-schema.md)。

## 入手方法

corpus の WACZ は **Git LFS** 管理。実体を得る方法は 3 つ:

```sh
# 方法 A: clone(git-lfs があれば実体まで smudge される)
git clone https://github.com/uraitakahito/waxlens-corpus

# 方法 B: 1 本だけ HTTP で取得(LFS の実体は media URL から。raw URL は不可)
base=https://media.githubusercontent.com/media/uraitakahito/waxlens-corpus/main/fixtures
curl -sL "$base/good.wacz" -o good.wacz

# 方法 C: waxlens から決定的に再生成(DL 不要・byte 同一)
CORPUS_DIR=../waxlens-corpus pnpm --filter @waxlens/core corpus:build
```

なお、この事例ページの[カタログ表](#標本カタログ)を再生成する `corpus:docs` は
`manifest.json`(LFS 対象外の素の JSON)しか読まないので、実体 WACZ も
`git lfs pull` も要らない。

## walkthrough

代表 3 本を `waxlens`(plain 出力)で実際に検証した例。出力メッセージは
ロケール依存(`--lang` / `WAXLENS_LANG` / `LANG`)で、以下は日本語ロケールの例。

### 黄金 — `good.wacz` → exit 0

全 rule を pass する黄金(browserhive producer)。`error` も `warning` も無い。

```text
$ waxlens good.wacz
waxlens 0.0.0  good.wacz

[✓] 14 other rule(s) passed

14 passed, 0 failed, 0 warnings, 0 info  · 10ms
1 record  ·  246 B  ·  1 host
```

### 構造欠落 — `wacz-missing-archive.wacz` → exit 1

`archive/` に WARC が無い(WACZ §5.2.1 の MUST 欠落)。`error` で exit 1、
spec の該当アンカー URL が併記され、Layout では欠落が `(missing — …)` で示される。

```text
$ waxlens wacz-missing-archive.wacz
[✗] wacz/required-files
    archive/ — archive/ に WARC ファイルがありません(WACZ §5.2.1: …)
      spec https://specs.webrecorder.net/wacz/1.1.1/#archive

13 passed, 1 failed, 0 warnings, 0 info

Layout
├── archive  (missing — required by §5.2) wacz/required-files
└── …
```

### producer 差 — `good-webrecorder.wacz` で profile を切り替える

同じアーカイブでも profile で結果が変わる典型。webrecorder producer は
gzip 済み CDXJ(`.cdx.gz` + `.idx`)を出す。`spec` では replay 可能なので
`warning`(exit 0)だが、plain な `.cdxj` を強制する `browserhive` では
`error`(exit 1)に escalate する。

```text
$ waxlens good-webrecorder.wacz --profile spec
[!] cdxj/index-not-gzipped
    indexes/index.cdx.gz — … gzip 圧縮された CDXJ です …
14 passed, 0 failed, 1 warnings, 0 info        # exit 0

$ waxlens good-webrecorder.wacz --profile browserhive
[✗] cdxj/index-not-gzipped
    indexes/index.cdx.gz — … gzip 圧縮された CDXJ です …
13 passed, 1 failed, 0 warnings, 0 info        # exit 1
```

`spec` で exit 0 なら [ReplayWeb.page](https://replayweb.page/) で replay できる
ことが期待される。profile ごとの severity は上の[カタログ表](#標本カタログ)の
「profile で severity が変わる標本」を参照。
